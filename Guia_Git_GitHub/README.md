# Guía práctica de Git y GitHub

Proyecto educativo desarrollado con HTML, CSS y JavaScript.

## Objetivo

Explicar los conceptos básicos de Git y GitHub, mostrar comandos frecuentes y presentar el procedimiento general para publicar un proyecto en GitHub.

## Archivos

- `index.html`: contenido y estructura de la guía.
- `style.css`: diseño y adaptación a pantallas pequeñas.
- `script.js`: interacción y manipulación del DOM.

## Cómo ejecutar

Abre `index.html` en un navegador web.

## Manipulación del DOM

JavaScript utiliza `querySelectorAll`, `getElementById`, `addEventListener`, `textContent`, `classList.add` y `classList.remove` para actualizar el contenido de la página cuando el usuario interactúa con los botones.
