01 — CONCEPTOS

¿Qué es Git?

Git es un sistema de control de versiones. Permite registrar los cambios realizados en los archivos de un proyecto, consultar versiones anteriores y trabajar de manera organizada.

Historial

Guarda un registro de los cambios realizados en el proyecto.

Ramas

Permite desarrollar funciones o probar cambios sin afectar la versión principal.

Trabajo local

Puede utilizarse en la computadora sin conexión permanente a internet.

02 — PLATAFORMA

¿Qué es GitHub?

GitHub es una plataforma en línea que permite alojar repositorios Git. Facilita compartir código, colaborar con otras personas y mantener proyectos disponibles en internet.

Git

Es la herramienta que controla las versiones del proyecto en el equipo local.

GitHub

Es el servicio en línea donde se pueden guardar y compartir repositorios Git.

03 — PRIMEROS PASOS

Instalación y configuración

  1. Descarga Git desde git-scm.com.
  2. Instálalo siguiendo las opciones recomendadas.
  3. Abre la terminal de tu computadora.
  4. Comprueba la instalación con git --version.
  5. Configura tu nombre y correo electrónico.
git config --global user.name "Tu Nombre"
git config --global user.email "tu-correo@email.com"

05 — PROCEDIMIENTO

¿Cómo subir un proyecto a GitHub?

1

Crear una carpeta

Guarda dentro los archivos de tu proyecto.

2

Inicializar Git

git init
3

Preparar los archivos

git add .
4

Crear un commit

git commit -m "Primer commit"
5

Crear un repositorio en GitHub

Inicia sesión en GitHub y selecciona New repository.

6

Conectar y publicar

git branch -M main
git remote add origin URL_DEL_REPOSITORIO
git push -u origin main

06 — CONCEPTOS IMPORTANTES

Palabras que debes conocer

Repositorio

Carpeta de proyecto cuyo historial de cambios es administrado por Git.

Commit

Registro de un conjunto de cambios con un mensaje descriptivo.

Branch

Rama de trabajo que permite desarrollar cambios de forma separada.

Remote

Referencia a un repositorio alojado en otro lugar, por ejemplo GitHub.
